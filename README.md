# HTTP Server from Scratch

I’m building HTTP servers in Python and C from scratch to deepen my understanding of networking and low-level CS fundamentals and become better at building systems.

- [`python/`](python/): the completed Python implementation, including gzip and concurrent persistent connections.
- [`c/`](c/): the completed C implementation, including gzip and concurrent persistent connections.

Both implementations passed all 14 CodeCrafters HTTP server stages. Each stage is retained as a separate implementation commit.

Each language has its own launcher and CodeCrafters configuration. Run commands from that language’s directory. Separate submission checkouts keep the source at the root expected by CodeCrafters; this public repository preserves both implementations together.
